# 複数銘柄への分散 (2026-09-30)

## 目的と条件

4h donchian_55_20 + 損切りのみ(利確なし)を、**パラメータを変えずに**複数銘柄で実行し、資金を均等に
配分したポートフォリオとして評価する。狙いは (1) 含み損の期間と最大DDを短く・小さくすること、
(2) BTCで決めたパラメータが他の銘柄でも機能するかの確認。

- 銘柄(結果を見る前に固定): 2018年初めの時価総額上位10で、現在もBinanceでUSDT建て取引できるもの
  = BTC / ETH / XRP / ADA / LTC / BNB。**生存バイアスあり**(その後に上場廃止・凋落した銘柄は含まれない)。
- 各銘柄: 訓練90日/検証30日のローリングwalk-forward、foldの損益を複利でつないだ曲線。
- ポートフォリオ: 各銘柄の曲線を日次で均等配分(上場の遅い銘柄はその時点から参加)。
- 実行: `python scripts/evaluate_portfolio.py`

## 結論

- **ポートフォリオでは「損をしない」基準をすべて満たした**: 最大DD 5.8%(許容10%以内)、
  下落局面・弱気相場の年で買い持ちより損が小さく、全期間でプラス。
- **分散はDDを大きく減らした**: 単独のBTC(8.8%)より、6銘柄の合成(5.8%)のほうが小さい。
  銘柄間の相関が0.16と低く、ある銘柄の損失を別の銘柄が埋めている。
- **ただしリターンは10%買い持ち(+7.16%)をやや下回る**(+6.42%)。リスクあたりのリターン
  (年率÷最大DD)は戦略1.1、買い持ち0.53で、戦略のほうが約2倍効率が良い。
- **銘柄単独では頑健ではない**: LTCは赤字でDD 26.5%、BNBは後半が赤字。単独で許容DD 10%を
  満たしたのはBTCだけ。BTCで決めたパラメータが全銘柄で機能するわけではなく、分散して初めて
  基準を満たす。
- **直近は弱い**: 2025年+0.44%、2026年+0.42%で、ほぼ横ばい。含み損の期間も最長923日と長い。
