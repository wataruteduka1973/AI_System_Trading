# Bot管理の見やすさ(Botと口座の状況)

状態: 実装済み(2026-10-08)。フロントエンドの視認性向上の第2弾(第1弾は `status-screens.md`)。

## なぜ

Bot管理の画面は、Botの名前・時間足・状態・直近シグナルの時刻しか出していなかった。
- 口座は「USDT口座」が12個、すべて同じ名前に見え、どれがどのBotの口座か分からなかった(入金・Bot作成の選択肢も同じ)。
- 銘柄・取引所、純資産、損益、建玉(FR-UI-01 / FR-UI-12)が、画面にも API にも無かった。

## 追加したもの

- **API**: `GET /workspaces/{id}/bot-overview`(ワークスペースのメンバーなら誰でも)。Botごとに、銘柄・取引所・状態・口座の純資産・入金額・入金に対する損益(%)・確定損益・手数料・取引数・
  開いている建玉(向き・数量・平均建値・現在値・含み損益・損切り)を返す。口座ごとに、その口座で動くBot名と、資産ごとの現金残高も返す。
  `app/trading/application/bot_overview.py`。純資産は `account_valuation.value_account`(Risk Gate が建玉の大きさを決めるのと同じ値)で、画面とBotの認識がずれない。
  何も保存せず、台帳・建玉・ローソク足を読むだけ。
- **Bot管理の画面**:
  - Botごとのカード: 名前・銘柄・取引所・時間足・状態、純資産、入金に対する損益、確定損益(手数料前)、手数料と取引数、建玉(あれば。現在値と含み損益、損切り)、直近シグナル(日付つき)、操作ボタン。
  - 上部の合計: 稼働台数・建玉のある台数、通貨ごとの純資産と入金比(JPY と USDT は足し合わせず、別々の行)。
  - 口座の一覧と、入金・Bot作成の選択肢は、「USDT口座 ac11ea0b(btcusdt-4h-donchian)」のように、使っているBotで区別する(Botが無ければ「Botなし」)。
  - 損益は、符号と色(緑/赤)の両方で区別する。幅375pxでもはみ出さない。
- 概要を読み込めていない間も、従来どおりBotと操作ボタンを出す(数字だけが無い)。

## 決めたこと

- `return_pct` は `(純資産 - 入金) / 入金`(手数料を引いた後の、入金に対する損益)。`realized_pnl` は閉じた取引の粗利で、手数料は別に出す。
- 口座の純資産は、いまは1口座=1Bot=1銘柄を前提にした評価(`account_valuation` の制約と同じ)。Botの無い口座は、台帳の現金残高だけを出す。
- 新しい表の追加は無い。口座に名前を付ける機能も作らず、Bot名で区別する(口座の名前が要るかは、複数Botの口座が実際に出てから決める)。
- エンドポイントは `/bots/overview` ではなく `/bot-overview`(`/bots/{bot_id}` と衝突するため)。
