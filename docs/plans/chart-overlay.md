# チャートへの取引の重ね表示(約定・損切り・建玉)

状態: 実装済み(2026-10-12)。取引の見える化の第3弾(第1弾: `trade-history.md`、第2弾: `decision-history.md`)。FR-UI-02「チャートにOHLCV、…、シグナル、注文、約定を重ねて表示する」の、注文・約定の部分。

## なぜ

取引履歴(表)と判断の履歴(説明)は、「いつ・何を」は分かるが、**価格の流れの中で**その取引がどう見えるかは分からなかった。損切りが、直前の下落のどこで、どれだけ手前で効いたか、
買いが高値の近くだったかは、チャートに重ねないと読めない。

## 追加したもの(バックエンドの変更は無い)

既存の `GET /workspaces/{id}/fills?instrument_id=`(取引履歴の約定)と `GET .../position-history?instrument_id=`(建玉)を、チャートの銘柄で読む。

- **市場の画面のチャート**(OANDA市場・Binance市場・公開履歴): そのワークスペースのその銘柄の取引を、ローソク足に重ねる。
  - **約定のマーカー**: シグナルの買いは緑の上矢印(足の下)、シグナルの売りは赤の下矢印(足の上)。損切り・緊急停止の決済は琥珀色の四角、ドテンの決済・手動は紫の四角。ラベルに「買い 20.953」「損切り 20.953」のように数量。
  - **決済済みの建玉**: 建値から決済価格までの点線(利益は緑、損失は赤)。
  - **保有中の建玉**: 建値(青の破線、「建値 買い 2」)と損切り(琥珀色の点線)の水平線。
  - **ツールチップ**: 約定のある足にカーソルを当てると、「約定 買い 20.953 @ 795.43」と、決済なら確定損益。
  - チャートの下に、「このワークスペースの取引を重ねて表示」のチェック(既定はオン)、約定の件数、凡例。読み込み済みの足より前の約定があれば、その件数と「チャートを左へ動かすと出ます」。取引が1件も無い銘柄には、チェックも凡例も出さない。
- 取引の取得は、市場の画面にいるときだけ、30秒ごと。失敗しても、いまの重ね表示を消さない(動いているチャートに、取得失敗のエラーは出さない)。長い履歴は、200件ずつ最大3ページ。

## 決めたこと

- **約定は、「その時点までに確定した最後の足」に置く**(`candleAt`)。ペーパーの約定は、最新の確定足の終値でつくられる(`order_flow._simulate_fill`)ので、約定価格はその足の終値になる。
  つまり、約定は、シグナルを出した足(例: 10/5 5:00〜9:00 の足の終値 795.43 で買い)に付き、いま開いたばかりの足には付かない。最初は「約定の時刻を含む足」に置いて、
  実データで、買いの矢印が1本ずれる(約定価格と合わない)のを見つけて直した。読み込み済みのどの足も、その時刻までに確定していなければ「読み込み済みの足より前」として数える。
- 重ね表示は、チャートの部品(`CandleChart`)に、描くものの記述(`ChartOverlay`: マーカー・線分・水平線・足ごとの約定)を渡す形にした。取引の取得・足への割り当て・描画を分け、割り当て(`buildChartOverlay`)は純粋関数でテストできる。
- 同じ足で建てて決済した建玉は、線分が引けないので、線は出さず、マーカーだけ出す。
- シグナルそのもの(約定しなかった買い・売り、拒否された売り)は、このチャートには出さない(判断の履歴にある)。

## 検証

- 単体(`chartOverlay.test.tsx` 16件): 足への割り当て(確定した最後の足、確定前、最新より後、最古より前)、マーカーの種類と向きと色、時刻順、足より前の約定の件数、ツールチップ用の足ごとの約定、
  建玉の線分(利益・損失の色、同じ足・出口の約定が無いときは無し)、保有中の水平線(損切りが無いとき)、チャートへの受け渡し(マーカー・線分・水平線、変更時に前の描画を消し、プラグインは使い回す、ツールチップ)、
  取引の取得(市場の画面だけ、カーソルをたどる、失敗しても保つ)、市場の画面のトグルと凡例(取引が無いときは出ない、オフのときは描かない、足より前の件数)。既存のチャートのテスト(`CandleChart.test.tsx`)も変更なしで成功。
- ローカル DB・ブラウザ(実データ。公開履歴の BNBUSDT・4h、10/5 の買いと 10/7 の損切り): 約定2件の凡例が出て、チャートに、シグナルの足(10/5 の足。終値が約定価格 795.43)に緑の「買い 20.953」の矢印、
  損切りの足に琥珀色の「損切り 20.953」の四角、その間に損失の赤い点線が描かれた。トグルをオフにするとマーカーと点線が消える。

## 未検証・限界

- 保有中の建玉の水平線(建値・損切り)と、利益の緑の線分は、ローカル DB に該当が無く、ブラウザでは見ていない(単体テストのみ)。
- 約定のある足にカーソルを当てたときのツールチップは、ブラウザでは、ピクセル位置を合わせられず見ていない(単体テストのみ)。
- 1分足など細かい時間足では、1本のシグナルの足が小さく、マーカーが重なりうる。
- 取引の取得は銘柄ごとに、最大600件(200件×3ページ)。それを超える履歴は、古い約定が出ない。
