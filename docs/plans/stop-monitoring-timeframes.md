# 損切りを監視する時間足の比較 (2026-10-04)

## 目的

利用者の懸念: 4h足を参照するだけでは急な値動きに対応できないのではないか。売買の判断は検証済みの4hのまま、
損切りの判定だけをより細かい足で行ったときに、(1) 損失(リスク)がどう変わるか、(2) 細かい足を生かした
トレーリングストップで利益をどこまで増やせるか、を検証した。

## 条件(結果を見る前に固定)

- BTCUSDT、約8.9年、4h donchian_55_20、ローリングwalk-forward(訓練90日/検証30日)
- 損切りを監視する足: 4h(従来)・1h・15m・5m。Binanceに10分足は無い
- 出口: `stop_loss`(固定の損切り、ATR×2)と `trailing_stop`(同じATR×2の幅で、エントリー後の最高値に
  合わせて切り上げる。切り上げた価格は次の足から使う)
- 実装: `run_replay(stop_monitor=...)`、`scripts/research/compare_stop_monitoring.py`

## 分かったこと

- **固定の損切りでは、監視の足を細かくしても損益は1円も変わらなかった。** 細かい足での判定は正しく効いている
  (決済時刻が4hでは12:00・16:00、5mでは11:00・13:35と、より早い時刻になる)。それでも約定価格が変わらない
  のは、暗号資産が24時間連続で取引されるため。5分足が直前の足の安値より0.3%以上下で始まる「足の間の窓開け」は
  9年で504回あったが、損切り価格をまたぐ瞬間と重なることは無かった。損切りは、どの足で見ても損切り価格で約定する。
- **足のデータでは、急落時のスリッページは再現できない。** 実際の約定の悪化は、足と足の間ではなく、注文の瞬間の
  板(買い注文の厚さ)で起きる。急落時の損失は、ステップ1のスリッページの検証(`docs/plans/multi-asset-diversification.md`、
  損切りのたびに1%悪くなってもポートフォリオの最大DDは7.2%)で見積もるのが妥当。
- **トレーリングストップは、損失をはっきり減らすが、利益をそれ以上に削る。** 最大DDは8.8% → 約6%、最悪の損切りは
  -2.61% → -0.77%に下がる。一方、年率は+7.75% → 約+1%に下がり、上位5区間への依存が100%を超える(少数の区間に
  依存)。固定の利確と同じく、トレンド追随の利益の源泉である「大きな上昇を最後まで取る」ことを妨げる。
  監視の足による差は小さい(年率+0.77%〜+1.06%)。
- **細かい監視で得られるのは、損益ではなく「気付くまでの速さ」。** 4hでは最大4時間後に気付くところが、5mなら最大5分、
  1mなら最大1分になる。ペーパートレードでは約定価格の計算は変わらないが、実際の取引では取引所側の損切り注文が
  即座に約定するので、システムが早く状態を知ることに意味がある。

## 結論

- 売買の判断は4h、損切りは固定(ATR×2)のまま。トレーリングストップは採用しない。
- 損切りの監視を細かくする(ステップ3、ペーパートレードの1分足監視)は、損益の改善ではなく、急落時にシステムが
  素早く状態を把握するための運用上の改善として行う。
- 急落時の損失の見積もりには、足のデータではなく、スリッページを仮定した検証(ステップ1)を使う。
